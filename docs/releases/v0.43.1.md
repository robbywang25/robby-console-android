# v0.43.1 · Token 额度小组件不再留白

Token 额度桌面小组件的各行改成均分标题下方的高度，拉高时行距跟着变大，底部不再空出一块；尺寸档补到 560dp 高。

- `widget_tokens.xml`：六行 `wt_row1…6` 改为 `layout_height=0dp` + `layout_weight=1` + `gravity=center_vertical`。显示出来的行平分剩余高度，隐藏的行不占位。所以格子比所选尺寸档高时，多出的高度也会分到各行，不会堆在底部。
- `GodWidgets.tokens`：去掉原来补在行距上的 `spare`（每行最多补 12dp，补不完的部分就成了底部空白），各行只保留原来的固定上边距。
- `GodWidgets.SIZES`：两种宽度都补上 400 / 480 / 560dp 三档，一共 16 档（`RemoteViews` 尺寸映射的上限）。正常字号下 330dp 已经能排满 6 行，新档位主要让调大字号后、拉高的小组件多排几行；其他四个数字小组件沿用同一套档位，画法不变。
- 没有改动：小组件显示的数据和脱敏规则、刷新时机、认证、`FLAG_SECURE`。

验证：289 项 JVM 测试、Debug/Release 构建与 lint 通过（lint 0 错误）。正式签名包覆盖安装到 Find（PMA110），versionCode 70，安装文件 SHA256 与构建一致（`1f83fe51…87c9c1c4`），签名为正式证书。桌面上已放的 Token 额度小组件（约 4×2）刷新后截图：9 个账号排成两列 5 行，行距均匀，底部没有空白。

已知问题（不是这次改动引入的）：覆盖安装后，ColorOS 桌面回到前台时会把 God 的小组件重置成初始占位布局，日志里先是 `forceUpdateAppWidget … remoteViews is null`，再是 `getDefaultView`。要等 God 再刷新一次小组件，比如打开 App，才会恢复。0.43.0 装上后出现的「一大块空白」就是这个原因。这一版没有修。

附 APK 与 SHA256SUMS，Android 11 及以上，可覆盖旧版。
