# v0.50.0 · 登录迁移到统一认证入口

新登录使用 auth.robby.wang。现有会话保留原身份服务信息，升级不会把旧刷新令牌发给新域，也不会直接清除登录。账户安全设置支持新旧两个明确入口。

- 原生 Passkey 与网页登录按当次身份服务校验 RP、回调和端点；取消或服务暂不可用不会伪造迁移成功。
- Apple / Google 独立登录流程保持。
- 新域需先登记可用 Passkey。彻底退役旧域前，各设备仍须完成一次新域登录和实际刷新验证。

本地 JVM、lint 与 Debug/Release 编译已通过；设备安装和新域真实登录验收单独记录。本发布包沿用既有正式签名，可覆盖升级。
