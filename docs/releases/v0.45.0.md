# v0.45.0 · 米家灯在你的每台手机上都能用

0.44.0 的米家灯只存在设置它的那台手机上。现在灯的名称、地址和 token 会和心力球的 Key 一样同步到你的 God 账号，登录同一账号的其他安卓手机打开「米家灯光」就能直接控制。

- 同步方式：沿用心力球的 `account/app-secrets` 文档，新增可选字段 `mijiaLight`。God 网关用 AES-256-GCM 封存后存入账号，账号服务只保存密文；需要 `god.mobile.profile.write`，没有新增权限。
- 兼容旧版：只有请求 `?version=2` 的新版才读写灯，0.44.0 及更早的版本仍只看到五个 Key，它们保存时会保留账号里的灯。网关还没升级时，新版自动退回旧接口，灯先留在本机，等网关升级后自动补传。
- 已有的灯：升级后第一次同步会自动上传，不用重新填写；如果别的手机存过更新的 Key，会先合并再上传。
- 修改与移除：在一台手机上修改或移除，其他手机下次同步时跟着变，页面会用新设置重新读灯。
- 什么时候同步：打开米家灯光页、保存或移除灯之后，以及打开 God 时（开着心力球或设置了灯，最多每 10 分钟一次）。
- 「连接」卡片新增「同步」一行，没有同步到账号时写明原因。
- 灯的名称最多 40 个字；0.44.0 存下的更长名称同步时自动截短。离线时的修改或移除，下次打开 God 会自动补发。

验证：308 项 JVM 测试通过（`AppSecretsSyncTest` 新增灯的上传、合并判断、文档校验、带版本号的写入放行和名称整形），Debug/Release 构建和 lint 通过，lint 0 错误。正式签名包覆盖安装到小米 MIX Flip，灯的状态照常读到，在旧网关下「同步」显示「仅本机」，没有崩溃日志。网关改动的单元测试 19 项通过。

附 APK 与 SHA256SUMS，Android 11 及以上，可覆盖旧版。
