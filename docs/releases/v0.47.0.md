# v0.47.0 · 颂钵与番茄钟，安静地专注

「功能 → 工具」新增颂钵：一只拟物铜钵，加上白噪音和番茄钟。声音全部在手机上实时合成，不打包任何录音。

- 轻点敲钵，敲在钵口更亮；沿钵口画圈它会持续「唱」，转得越快越响。有大钵 196 Hz、中钵 262 Hz、小钵 392 Hz 三只。
- 钵声参考 GitHub 上的开源颂钵合成（evoluteur/tibetan-singing-bowls 和一组真钵实测频谱）：五个不规则泛音，每个由两条相差几赫兹的正弦组成，所以会嗡嗡起伏，余音很长。
- 环境音可选白噪音、粉红噪音、棕噪音和雨声，也可以打开「持续唱钵」；颂钵和环境音各有音量。
- 番茄钟默认专注 25 分钟、休息 5 分钟、每 4 轮长休息 15 分钟。每段结束时颂钵会响（专注结束三声、休息结束一声），手机轻震一下并发一条提醒。
- 熄屏或离开 God 后声音和计时照常，通知栏里可以暂停或停止；来电或别的 App 开始播放时，环境音会停下。
- 时长、钵和两个音量跟着账号同步到你的其他安卓手机。

验证：325 项 JVM 测试通过（新增合成器和番茄钟的测试），Debug/Release 构建和 lint 通过，lint 0 错误。MIX Flip 上检查了预览版的浅色、深色和大字体画面，以及敲钵、计时、雨声播放和前台服务；正式签名包覆盖安装到 Flip，安装文件与构建产物 SHA256 一致，启动无崩溃。

未验证：手指画圈的手感、熄屏后到点响钵、来电时停止环境音，需要本人试。

附 APK 与 SHA256SUMS，Android 11 及以上，可覆盖旧版。
