# v0.42.0 · 心力球看板，功能分区按最近使用

心力球新增看板，设置收进右上角齿轮；「功能」的三个分区也按最近打开排序。录音、转写、整理流程和数据只在本机的边界不变。

- 心力球页顶部新增「看板 / 记录」切换，默认看板：录音开关与状态；今天的录音分钟、关键事项、未完成待办、摘要和最近 3 条关键事项；近 7 天未完成的待办（可直接勾选，最多 8 条）；近 7 天录音时长、录音天数、待办完成数和每日录音柱状图。
- 「记录」是原来的按天切换、时间线和录音原文。
- DeepSeek / 转写服务的 Key 与服务、录音通知、多台手机同步、说明和「清除全部录音与记录」移到标题栏齿轮打开的「心力球设置」子页，返回回到心力球。
- 洞察、资产、工具三个分区按各自最近打开的功能排序，都没打开过时保持目录顺序；分区内的排序不变。
- 看板只读这台手机最近 7 天的记录文件，不新增任何网络请求。

真机验收（小米 MIX Flip，HyperOS / Android 16，展开内屏）：预览版在浅色、深色、1.6 倍字体下检查了看板、记录、心力球设置和返回、功能分区排序；验收中修掉了大字体下数字列和坐标轴折行的问题。正式签名包用 adb 覆盖安装 0.41.0，安装文件 SHA256 与构建一致，启动后无崩溃日志。

限制与未验证：Find X9 Ultra 当天不在线，没有在 Find 上安装；Flip 上没开录音，看板上的真实录音数据没有验证；登录后页面截不了图。仍为预览版。
