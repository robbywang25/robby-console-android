# v0.49.0 · 同一供应商的额度账号排在一起

Token 额度页、看板和额度小组件现在使用同一套供应商与账号权重。Gemini 的多个账号归在同一组；刷新、额度变化和数据过期不会把账号顺序打乱。

- 优先采用服务端共享权重；旧接口或缺少字段时使用一致的默认顺序。
- 支持独立的扩展账号列表，保留原来的接口数组和账号 ID；同一账号重复出现只展示一次。
- 双列额度小组件把同供应商的账号放在一起，单账号之后也不会把下一组拆到两行对角。
- 默认顺序为 OpenAI、Claude、Grok、Cursor、TodayAI、Gemini；同供应商内按账号权重排列。
- 保留已安装版本中的颂钵、番茄钟和云剪贴板正文功能。

验证与限制：共享排序的 JVM 回归覆盖顺序变化、权重冲突、非法或新版元数据、扩展列表去重和小组件排序。当前两台验证手机都没有在线 ADB 连接，本轮未完成新版本真机安装或真实账号视觉验收。

附 APK 与 SHA256SUMS，Android 11 及以上，可覆盖旧版。
