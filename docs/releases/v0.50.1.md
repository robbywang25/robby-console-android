# v0.50.1 · 同步设置时保留其他客户端的键

安卓上传账号设置（`POST account/preferences`）时，不再删除自己不认识的键。God iOS 同步的 `quotaCalendarFiveHour`、`quotaCalendarHideExpired`、`quotaCalendarWeeklyOnly` 及其 `editedAt` 时间，此前会在安卓每次上传后丢失。

- 上传文档以上次的服务器文档（base）为底，保留所有未知键和它们的 `editedAt` 条目，再叠加安卓自己的 `KEYS`；普通上传和 409 冲突重试都一样。
- 本机保存的 base 也带上未知键，重启后依然有效；同版本拉取会刷新旧版本存下的 base，避免升级后第一次上传仍然删键。
- 未知键沿用原有的形状规则：含 signature/avatar/token/secret/password 的键或值、嵌套超过 4 层的值不会上传；16 KiB 上限照旧（超限时先裁最近使用记录）。
- 安卓已知键的读取、合并和按编辑时间取胜的规则不变。
