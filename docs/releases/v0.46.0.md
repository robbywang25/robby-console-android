# v0.46.0 · 看板额度多了十格余量条

看板的 Token 额度卡片在每个账号名称下面加了一排十格余量条，一眼看出哪个账号快用完了。详情页和桌面小组件不变。

- 一格代表 10%：只要还有余量就至少亮 1 格，满额才亮满 10 格。
- 颜色与小组件一致：余量 ≥50% 绿、20%～50% 琥珀、<20% 红；读数不是最新时灰色。
- Claude 的 5 小时和每周额度各一排，左侧标注，两排格子对齐，调大字号也不错位。
- 读取时先画一排未亮的格子，读到数字后卡片不会突然变高。

验证：311 项 JVM 测试通过（新增亮格数的边界测试），Debug/Release 构建和 lint 通过，lint 0 错误。Find X9 Ultra 上预览版检查了浅色、深色、大字体下的看板；正式签名包覆盖安装到 Find，安装文件与构建产物 SHA256 一致，启动无崩溃日志。

未验证：读取占位那一帧；登录后的真实看板需本人查看。
