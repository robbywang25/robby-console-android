# v0.51.0 · 熄屏时番茄钟准时响钵

颂钵番茄钟的阶段结束提醒改用系统闹钟（`AlarmManager.setAlarmClock`）。此前用的是 `setExactAndAllowWhileIdle`：在 HyperOS（小米 MIX Flip）上，熄屏约 5 秒后 God 会被冻结（`GreezeManager: FZ uid … reason=screen off`），前台服务也挡不住；精确闹钟到点时被系统扣下（`cached alarm!`），要到亮屏才补发。补发时阶段已结束超过 60 秒，颂钵不再响，只会跳到下一段。

- 闹钟的 show intent 打开颂钵页；计时期间状态栏显示闹钟图标，系统时钟的「下一个闹钟」也会显示它。
- 没有精确闹钟权限时，仍回退到 `setAndAllowWhileIdle`，与之前相同。
- 计时状态、阶段推进、补发时 60 秒内才响钵的规则，以及前台服务和通知都不变。
