# v0.52.0 · 额度全量视图与四大移动控制面

全面对齐 SoT 移动契约与控制面升级，补齐 Token 目录、三视图预测、云剪贴板写入、工程 V2 以及四大原生移动能力。

- **控制面与 SoT 闭环**：接入 `/api/mobile/v1/bootstrap` 本地缓存发现协议，支持动态链接与端点路由；`engineering*` 响应安全上限提升至 1 MiB；全量消费 `quotas.catalog` 与 `catalogAccounts`（含编号 `Gemini 1/2/3`、`Antigravity 2`、`widgetPriority`、`unsubscribed`、`calendarEligible`、`renewal`）；端到端打通 `quotaCalendarCodingOnly`（重置日历页「只看 Coding」、看板编辑与桌面小组件及跨端设置同步）。
- **清洁与新鲜度**：移除已下线的 `PostHog` 功能页与卡片；默认放开 `Umami` 访问统计；为微信消息与 Token 额度增加超 2 小时未更新的琥珀色陈旧提示条。
- **三大体验升级**：
  - Token 额度新增三段切换（`按服务商 | 按邮箱 | 续费台账`）、`TokenForecast` 消耗速率与耗尽 ETA 预测、以及 `TokenDeviceActivity` 设备与在线 Agent 监控页；
  - 云剪贴板支持新建私密剪贴（7 天 / 30 天）、切换公开/私密可见性与移入回收站（附带 `AlertDialog` 确认及小写 UUID v4 幂等键，保持 OAuth scope 不变并在 `federated` 或 `403` 时清晰提示）；
  - 源码与工程支持仓库胶囊筛选、提交详情展开以及受限校验后的 GitHub 外部直达链接。
- **四大新增原生功能**：`AI 调度总控`（宿主机/Agent/认领队列与确认态暂停恢复/释放重试）、`基础设施哨兵`（告警/主机续费/存储/证书/模型 API 余额/发布校验/微信归档鲜度）、`提示词速查表`（支持 403/离线/未配置平滑降级至内置+本机模板、`{{变量}}` 填充弹窗与一键复制）、以及 `心力球` 活动与历史轮次一键投递 Flobo。
