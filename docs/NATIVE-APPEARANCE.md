# 原生界面

当前版本采用 Liquid Glass 风格（v0.4），规格和取舍见 [PRODUCT-STYLE.md](PRODUCT-STYLE.md)。下方 v0.3.x 的记录保留为历史，不是当前默认样式。Android 使用平台原生 View 和矢量资源，不引入第三方 UI 库。

## 组件

- `ConsoleTheme` 统一配色和材质：天空渐变背景；内容卡片 24dp，半透明，顶部带高光边；控制层玻璃包括圆形按钮、Dock 和选中胶囊；胶囊形按钮；14dp 输入框；对话框是完全不透明的玻璃面，带高光边。Find 上的跨窗口模糊没有生效，哪怕 98% 不透明也会透出背后页面的文字，所以完全不做透明。还包括状态色点、类别着色图标块，以及按压下沉回弹的效果。
- `GlassPane` 是底部 Dock。Android 12 及以上会把下方页面录制到独立的 RenderNode 上并做模糊，每帧绘制前重新录制，但不主动刷新 Dock 自身，所以不会额外驱动帧。它同时负责选中胶囊的布局和滑动动画。
- 页面结构：状态栏下面是固定页头。Tab 根页左侧是日期或「God 工作台」小字加大标题，右侧是圆形操作按钮；详情页左边是返回圆钮，中间是居中标题，右边是刷新或「+」圆钮。滚动内容在页头下方淡出，并一直延伸到悬浮 Dock 后面。
- 总览：第一张卡片回答服务健康（几项在线，几项未在线或状态未知），下面是云实例和域名两张指标卡，点击可进入详情，最后是待办提醒。
- 详情数据卡：键值行之间有细分隔线；状态值前加色点，文字始终保留；快照时间显示为带色点的玻璃胶囊。
- 列表：分组卡片，每行是类别着色图标块、标题、一行说明和箭头。仅展示信息的行没有箭头，也不可点击。
- 账本：「记一笔」在页头的「+」圆钮上；上一页和下一页并排；编辑、人员、最近删除、核实提交、切换账本放在同一张分组列表里。准备、确认、提交、回执与恢复流程不变。
- 降级：Android 11、关闭动画、省电模式及高对比文字模式下，不做实时模糊、不做按压和过渡动画；高对比模式下背景改为纯色，卡片加描边。
- 大字体下指标卡和键值行改为上下堆叠，控件至少 48dp，数据行允许增长，不截断金额。

主题跟随设备浅色/深色设置。业务内容继续在后台清除，正式登录界面继续使用 `FLAG_SECURE`。

## 独立视觉预览

Debug 构建是独立的 `wang.robby.console.android.preview` 应用，显示“界面预览 · 合成数据”，数据来源只在 `src/debug` 中。登录和写入被禁用，预览不接收正式 App Link。Release 的 `PreviewMode` 固定关闭，APK 不包含预览 Activity 或合成数据。

```sh
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n wang.robby.console.android.preview/wang.robby.console.android.PreviewActivity
adb shell 'am start -n wang.robby.console.android.preview/wang.robby.console.android.PreviewActivity\$Dark'
adb shell 'am start -n wang.robby.console.android.preview/wang.robby.console.android.PreviewActivity\$Large'
```

这些入口只覆盖预览应用的显示配置，不修改设备的全局主题或字体。可检查首页、五栏导航、功能列表、返回、滚动、设置和已有示例详情。未提供合成数据的功能显示预览限制，不请求真实服务。

视觉验收不能替代真实登录或业务数据验收；两者分别记录在发布说明中。

## v0.3.3：图标导航

按用户要求取消 Tab 可见文字，保留五个图标、无障碍名称、选中态和长按提示。以 Ledger 已有 dock 的样式值为准，不引入额外渐变：82% panel-strong、24 dp 模糊、32 dp 外圆角、1 dp 混合边框、轻阴影和顶部高光；选中项只覆盖10%强调色。图标24 dp，触控高度56 dp，间隔4 dp，外侧12 dp、底部安全区外10 dp。Android与网页的模糊、阴影由各自平台渲染，参数对齐不等同跨平台逐像素相同。高对比/省电/低版本降级保留。

## v0.3.4：固定底栏、黑白主题与 God Logo

底栏位于原生纵向布局的底部，横向铺满可用宽度，与系统手势安全区衔接。滚动区域在底栏上方结束；没有悬浮外边距、阴影、圆角背景、模糊或选中胶囊。Tab仍不显示文字，保留56dp触控高度、无障碍名称和长按提示。所有Tab保持同一黑/白颜色，仅切换outline/solid矢量资产表示选中。

`artwork/god-halo-source.svg` 来自 God 网页 `src/god-halo.svg`，原光环和人物路径用于 Android 启动图标及总览Tab的黑白适配。洞察柱状图复用Ledger SVG的三柱轮廓；资产、工具、设置保持各自语义并以本项目的独立矢量资源表达，不把五个功能都替换成同一个Logo。图标在 `res/drawable/tab_*` 中，后续可逐个替换，不再依赖Canvas手绘Tab。

此轮不修改认证、接口、会话或业务写入。

## v0.3.5：腾讯蓝强调与紧凑底栏

白/黑背景和黑白图标保持。主按钮使用腾讯TDesign标准蓝 `#0052D9` 与白字；浅色链接/焦点同色，深色链接/焦点使用TDesign对应 `#4582E6`。Tab和功能符号仍黑白，选中只填充图标，不染蓝、不加背景。

Tab触控高度48dp，上下留白各2dp，底栏主体52dp，比v0.3.4减少20dp；系统手势安全区另计。控件触控高度不低于48dp。

## v0.4：Liquid Glass（2026-10-15）

参照与依据：TodayAI Android 1.21.1 在 Find 上的界面（渐变背景、大标题、圆形玻璃按钮、悬浮 Dock）、Liquid Glass 的分层原则（控制层浮在内容之上，内容本身不加玻璃装饰），以及微信「先给结论、一个主操作、克制」的产品取舍。规格见 [PRODUCT-STYLE.md](PRODUCT-STYLE.md)。

验证：
- 构建与测试：CI 同款任务 `testDebugUnitTest lintDebug lintRelease assembleDebug assembleRelease` 全部通过，56 项 JVM 测试无失败，两个变体的 lint 均无错误。正式签名 Release 的证书 SHA-256 与此前正式版一致（`83d624e0…3da569`）。
- 真机（OPPO Find X9 Ultra，Android 16）：用预览应用的合成数据逐页检查了浅色的总览（含滚动后）、洞察、市场看板详情、工具、账本列表、账本详情（「+」记一笔）和「我」，深色的总览和对话框，以及 1.6 倍大字体的总览和详情。
- Dock 背后的实时模糊已在截图中确认；切换 Tab 时，紧接着截到的帧显示胶囊仍停在上一个 Tab，说明是从原位滑过来的。
- 真机检查后修正：Dock 文字居中；大字体时 Dock 加高到 72dp；手势条下方加底部渐隐；对话框改为不透明（跨窗口模糊未生效，98% 不透明仍透出背后的文字）。
- 未验证：ColorOS 禁止 adb 录屏，动画的完整过程只看了单帧；真实账号的数据、登录和写入流程本轮没有执行，这次改动也没有触及这些逻辑。
